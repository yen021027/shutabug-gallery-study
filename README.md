# Shutabug 展廊復刻

用瀏覽器開啟 `dist/index.html` 即可使用。程式、字型和作品縮圖都隨附於專案內。若要透過本機 HTTP 預覽，在此資料夾執行 `python -m http.server 8037 --bind 127.0.0.1 --directory dist`。

首頁可以拖曳、捲動或按左右鍵漫遊。點選畫作可放大預覽，再進入商品頁。右上角可切換展廊與清單。搜尋快捷鍵為 Ctrl+K 或 ⌘K。

目錄取自 [Shutabug](https://shutabug.com/) 的公開展示資料，共 18 個系列、268 筆系列收錄、241 個不同的商品編號。作品與標誌屬原創作者；隨附的 Barlow Condensed 字型授權位於 `dist/assets/font-license.txt`。

收藏與購物袋儲存在瀏覽器。商品規格沿用代表性版畫的示範價目，各幣別採固定預覽匯率。登入、電子報與實際購買會前往原站；拍賣頁呈現擷取當時的空檔狀態。
